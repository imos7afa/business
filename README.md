# Imos7afa — وب‌سایت خدمات شخصی تکنولوژی

سایت استاتیک فارسی (RTL) با HTML/CSS/JS ساده؛ بدون build، Node یا بک‌اند.

## استقرار روی GitHub Pages
1. محتوای این پوشه را در ریشه مخزن `imos7afa/business` (شاخه `main`) قرار دهید و commit/push کنید.
2. در GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**، شاخه `main` و پوشه `/ (root)` را انتخاب و Save کنید.
3. پس از چند دقیقه: https://imos7afa.github.io/business/

همه لینک‌ها نسبی‌اند و در زیرمسیر `/business/` کار می‌کنند. تنها استثنا `404.html` است که به `/business/` اشاره می‌کند (اگر نام مخزن تغییر کرد، آن را ویرایش کنید). آدرس‌های canonical و `sitemap.xml` هم از `https://imos7afa.github.io/business/` ساخته شده‌اند.

## فونت
فایل `Vazirmatn-Variable.woff2` را در `assets/fonts/` بگذارید (نام دقیق همین). تا آن زمان از Tahoma/فونت سیستم استفاده می‌شود.

## محدودیت‌ها
- فرم تماس پیامی ارسال یا ذخیره نمی‌کند؛ متن را کپی می‌کند و تلگرام را باز می‌کند، یا با پیامک می‌فرستد.
- تصویر Open Graph تنظیم نشده است؛ در صورت نیاز یک `og:image` اضافه کنید.


## نسخه ارتقای بصری و جستجوی هوشمند
- رابط کاربری روشن‌تر، فاصله‌گذاری و تایپوگرافی خواناتر، کارت‌ها و حالت‌های تعاملی به‌روزرسانی شده‌اند.
- تصویرهای محلی در `assets/images/` قرار دارند و به اینترنت خارجی برای نمایش تصویر نیاز ندارند.
- جستجو از هم‌معنی‌های رایج فارسی، نگارش‌های متداول اصطلاحات فنی، تطبیق عبارت کامل و تحمل خطای تایپی ساده پشتیبانی می‌کند.
- ساختار صفحات، مسیرها، فهرست خدمات و فایل‌های سئو حفظ شده‌اند.
- تصویرهای موجود در این نسخه، تصویرسازی‌های برداری محلی هستند؛ عکس مستند/عکاسی واقعی نیستند.
